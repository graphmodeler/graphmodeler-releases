# Graph Modeler downloads

[Graph Modeler](https://graphmodeler.com) builds graph models from rows of data, draws them with Graphviz, and publishes them as pictures,
DOT and Knowledge Graph files. This repository holds only the downloads. The source is private.

**Get it:** open [Releases](https://github.com/graphmodeler/graphmodeler-releases/releases) and choose the file for your computer.

| Computer | File |
| --- | --- |
| Windows 10 or 11, 64-bit | `Graph-Modeler-Setup-<version>.exe` |
| macOS 13 or later, Intel or Apple silicon | `Graph-Modeler-<version>-universal.dmg` |
| Linux, Debian or Ubuntu family, 64-bit | `graph-modeler_<version>_amd64.deb` |
| Linux, anything else, 64-bit | `Graph-Modeler-<version>.AppImage` |

Graph Modeler needs [Graphviz](https://graphviz.org/download/) to draw pictures. Everything else works without it.
The [Download page](https://graphmodeler.com/download/) says how to install it and what to expect from an unsigned beta.

**Check a download.** Each release has `SHA256SUMS.txt` and a signature, `SHA256SUMS.txt.asc`, made with this key:

`82B4 ECBE 7270 EA17 6430 9DBF 5C39 AD68 084C 132C` (Graph Modeler Releases <support@graphmodeler.com>)

The key is at https://graphmodeler.com/graph-modeler-release-key.asc. The steps are on the
[Download page](https://graphmodeler.com/download/#check-your-download).
