# Graph Modeler downloads

[Graph Modeler](https://graphmodeler.com) builds graph models from rows of data, draws them with Graphviz, and publishes them as pictures,
DOT and Knowledge Graph files. This repository holds only the downloads. The source is private.

**Get it:** open [Releases](https://github.com/graphmodeler/graphmodeler-releases/releases) and choose the file for your computer.

| Computer | File |
| --- | --- |
| Windows 10 or 11 | `Graph-Modeler-Setup-0.1.0.exe` |
| macOS, Intel or Apple silicon | `Graph-Modeler-0.1.0-universal.dmg` |
| Linux, Debian or Ubuntu family | `graph-modeler_0.1.0_amd64.deb` |
| Linux, anything else | `Graph-Modeler-0.1.0.AppImage` |

Graph Modeler needs [Graphviz](https://graphviz.org/download/) to draw pictures. Everything else works without it.
The [Download page](https://graphmodeler.com/download/) says how to install it and what to expect from an unsigned beta.
